VaultCap — Security

Last updated: July 2026 · Capricorn Systems

VaultCap does not use email/password accounts. Your vault is encrypted on your device before it is stored.

Your keys

ControlWhat it does
6-digit PINUnlocks the vault on this device only
Master recovery keyShown once at setup — reset PIN on-device if forgotten
.vos backupEncrypted export you control — move to another device
Decoy PINOptional second PIN opens an empty honeypot vault

PIN and keys are never sent to Capricorn Systems. We cannot open your vault or reset your PIN remotely.

Forgot PIN

  • Master key → Forgot PIN on lock screen → verify key → set new PIN
  • .vos backup → import on any device, then unlock
  • Neither → only option is reset (wipe). Support cannot decrypt your data.

Vault ID (VC-XXXX-XXXX) is a support ticket label only — not a password.

Encryption

  • AES-256-GCM vault encryption
  • PBKDF2 key derivation (310k iterations)
  • Brute-force lockout after failed PIN attempts
  • No automatic vault wipe — recovery via master key is always offered first

Smart Import / network

Core vault features work offline. Optional network use:

  • Live FX / gold rates (public APIs, cached)
  • Smart Import LLM via vaultos-llm-proxy.shamikhahmed.workers.dev — only text you paste is sent, never your PIN or full vault

Do not paste full card numbers or passwords into Smart Import.

Report a vulnerability

Open a private security issue on GitHub or email support@capricornsystems.com.
