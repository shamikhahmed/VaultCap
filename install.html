How your data is protected

No email / password account. That would need our servers. VaultCap is zero-knowledge:

  • 6-digit PIN — your password. Unlocks the vault on this device only.
  • AES-256-GCM — vault encrypted before it touches disk.
  • PBKDF2 (310k) — PIN → key; slow for attackers, fast for you.
  • IndexedDB / local storage — encrypted blob stays in the browser profile on your phone or laptop.
  • Master recovery key — shown once at setup. Save it offline. Recovers vault if you forget PIN.
  • Decoy PIN — optional second PIN opens an empty vault under duress.
  • Lockout — failed PIN attempts slow down, then block.

PIN and keys never leave your device. We cannot reset your PIN. Export .vos backups yourself for a second device.

Why not email + password?

Cloud login means we store accounts, reset passwords, and become a target. VaultCap’s model: you hold the keys. PIN = password. Master key = recovery. Optional Smart Assistant never needs your vault PIN.

Move to a new phone

  1. Old device: Settings → Backup → export encrypted .vos
  2. Or use QR sync between devices on the same network
  3. New device: install PWA → import backup → enter PIN / master key
