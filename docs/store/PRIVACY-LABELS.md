# VaultCap — App Store privacy nutrition labels (draft)

Publisher: Capricorn Systems. No analytics (G-9). No tracking. Network features opt-in (D-08).

| Data type | Linked to you | Tracking | Purpose | Notes |
|---|---|---|---|---|
| Photos or Videos | No | No | App Functionality | Optional; encrypted in vault on device |
| Financial Info | No | No | App Functionality | Banks/cards/loans stored encrypted on device only |
| Other User Content | No | No | App Functionality | Documents, notes — on device |
| Product Interaction | No | No | App Functionality | App preferences via localStorage / UserDefaults |

**Optional network (user must enable):** institution name/domain for logo proxy; FX/metals rates; per-use Smart Import fields to LLM proxy. Defaults **off**. Not used for tracking or advertising.

**Not collected:** contact info for advertising, advertising identifiers, diagnostics sold to third parties.
